# Car Dealership Management System

Web-based platform built for **ITM 4900 Senior Design** to centralize vehicle inventory, customer search/comparison, and secure online transactions for a car dealership.

## Problem
Car dealerships often rely on manual or disorganized methods to track vehicle, transaction, and customer-based information, which slows operations and creates inventory/pricing mismatches.

## Solution
A centralized system that:
- Tracks vehicle inventory in real time (add, update, remove, view)
- Lets customers search and compare vehicles by features, specs, and price
- Supports secure online transactions with automated receipt generation
- Enforces role-based access control and PCI DSS–aligned handling of cardholder data
